# 泰达的账本 · 热榜快照

每小时自动抓取一次国内主要热榜（微博、知乎、百度、头条、微信热文、抖音、快手、贴吧、什么值得买、腾讯热问、新浪热榜、新浪财经、第一财经、华尔街见闻、雪球、网易、澎湃、中新网、IT之家、36氪、虎嗅），存档供《泰达的账本》每日选题使用。

- `data/日期/HHMM.json`：每次快照（北京时间）
- `data/日期/summary.md`、`summary.json`：当天汇总，记录每个标题的首次/最后出现时间、在榜次数、最高排名、上榜平台
- 只保留最近 30 天

数据接口参考开源项目 [yiktt/hotboard](https://github.com/yiktt/hotboard)（MIT）。榜单内容版权归各平台所有，本仓库仅作个人选题参考。
