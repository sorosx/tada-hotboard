# 泰达的账本 · 热榜快照

每小时（北京时间）自动抓取一次国内主要热榜：微博、知乎、百度、头条、微信热文、抖音、快手、贴吧、什么值得买、腾讯热问、新浪热榜、新浪财经、第一财经、华尔街见闻、雪球、网易、澎湃、中新网、IT之家、36氪、虎嗅（微博、头条另有官方接口备份），共 23 个来源。

## 目录

- `data/日期/HHMM.json.gz`：每小时一份快照（北京时间），保留 30 天
- `reports/日期_钱包线索.md`：当天去重后，和普通人钱包有关、不触红线的标题（关键词粗筛，全部未核实）
- `reports/日期_新闻汇总.md`：当天全部去重标题，含“重点”一节，并按时政国际、财经资产、民生消费、社会其他、科技数码、文娱体育、灾难事故分组
- `reports/日期_全部.json`：上面两份的原始数据

每日报告在北京时间 23 点生成，0 点补全前一天。随时生成任意时段：

```
python3 scripts/build.py --last 24 --out 输出目录     # 截至现在的过去 24 小时
python3 scripts/build.py --date 2026-10-30            # 某一整天
```

## 运行方式

GitHub Actions 每小时触发两次（第 7、37 分），同一小时只存一份，防止 GitHub 繁忙时跳过。只用 Python 标准库。

数据接口参考开源项目 [yiktt/hotboard](https://github.com/yiktt/hotboard)（MIT）。榜单内容版权归各平台所有，本仓库仅作个人选题参考。
